# just-type-ime

Version info for the [Just Type IME](https://github.com/littlexiaocai/just-type) Obsidian plugin.
The plugin's optional update reminder reads `version` and `justType.headline` from this package's
metadata (via registry.npmmirror.com, which is reachable from mainland China). It is not a library.

Just Type IME 插件的版本信息包。插件的「有新版本时提醒」通过 registry.npmmirror.com 读取本包的
`version` 与 `justType.headline`（国内可访问）。这不是一个代码库。
